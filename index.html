seraph released 9/16/26

Seraph doesn't live on the web anymore.

seraphweb.com no longer serves games. Every game is now a single file you download once and keep on your iPad. Nothing to load, nothing to block.

Open the games folder

It's a Google Drive folder — sign in with your school account. The full instructions, with pictures, are in the READ ME doc inside it.

What changed

Websites get blocked. Files on your own iPad don't. So instead of a site you visit, each game is now one .html file with the whole game packed inside — the engine, the graphics, the sounds, everything. You download it once and open it in PDF Expert, and it runs right there on the iPad, offline.

Old bookmarks for the games all land on this page now. There's nothing else here to find.

What you need

PDF Expert on your iPad
Install it from Mosyle Manager, the school app store. It's free there.
A bit of space
Games are 1–40 MB each. The whole set is about 275 MB.
Internet once
Only for the download. After that the game runs with no Wi-Fi at all.

How to play a game

  1. Download the game from the folder

    Open the games folder in Google Drive, tap the ⋮ next to the game you want, then Download.

  2. Find it in the Files app

    It lands in iCloud Drive → Downloads. If the size is still growing, give it a minute — the bigger games take a bit.

  3. Tap the file, then tap “PDF Expert”

    The button is in the top-right corner of the preview. That's the whole trick.

  4. Wait for the loading bar, then play

    First launch takes 10–30 seconds while the game unpacks out of the file. Turn the iPad sideways for most of these. Once it's in PDF Expert, you can reopen it anytime without downloading again.

Or get everything at once

The folder also has seraph-games.zip — every working game in one 165 MB download. Do it on Wi-Fi.

  1. Download the zip

    Same as before: ⋮ next to seraph-games.zip, then Download. It takes a few minutes.

  2. Tap it once in Files

    It unpacks into a Seraph Games folder right next to it.

  3. Open a game, tap “PDF Expert”

    Exactly like step 3 above. Now every game is on the iPad, and you only need Drive again when something gets added or fixed.

Good to know

Keyboard games
Slope, Slope 2, Slope City, Snow Rider, Rocket Soccer, Vex and Gun Mayhem 2 are built for arrow keys, so they play best with a keyboard case. BitLife, Retro Bowl, Tiny Fishing and Wordle are all touch.
No sound?
Tap the screen once. iPads keep audio off until you touch the page.
Saves
Some games remember your progress between opens — Retro Bowl, BitLife, best scores in Slope 2. It's stored inside PDF Expert on that iPad. Not well tested, and not guaranteed to survive a re-download or a reinstall. Don't count on a long career surviving.
Don't rename the file
It has to stay .html or PDF Expert won't run it.

If something's wrong

Black screen or a stuck loading bar
Give it a full 30 seconds. Still nothing? Close the file, swipe PDF Expert away, reopen.
Won't open, or shows a wall of code
The download didn't finish or the file got renamed. Delete it and download it again.
PDF Expert closes itself
Out of memory. Close every other app and try again. Rocket Soccer, Slope City and Gun Mayhem 2 are the heaviest.
Snowbattle.io stuck on “connecting”
It's the one online game here. It needs Wi-Fi, and it's unstable even then.

Updates

Games get added and fixed weekly, released every Friday by 11:59pm. Every change is written in the update log at the bottom of the READ ME doc in the folder — check the date there if a game seems off, and re-download anything marked as fixed. The zip is rebuilt at the same time.
